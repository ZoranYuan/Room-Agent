# 独立问题检索评测：K20 / L10 / 精排输入5 / N3

复用前一轮保存的 2,490 个原始消息子块。选取已有 v5 题集中 150 道单证据独立问题（100 道时间题、50 道无时间题），未重新聚类、未调用 LLM 处理问题或生成答案。LLM API 请求数为 0；本地运行 Embedding 和 Reranker。

| 参数 | 值 |
|---|---:|
| Dense 初次召回 K | 20 |
| BM25 初次召回 K | 20 |
| RRF 保留 L | 10 |
| Reranker 输入 | 5 |
| 最终输出 N | 3 |
| RRF 平滑常数 | 60 |
| 时间排名权重 | 0.25 |

当前 LlamaIndex Milvus 接口将两路请求 limit 和融合输出 limit 绑定到 similarity_top_k。本脚本请求两路各20并获得RRF排序的前20项，再截取前10项，实现L=10。

| 条件 | 命中题数 | Recall@3 | MRR@3 |
|---|---:|---:|---:|
| 关闭时间因素 | 99/150 | 66.00% | 0.5022 |
| 开启时间因素 | 126/150 | 84.00% | 0.7144 |

每题有一个正确证据组，可能对应多个包含同一答案的可接受子块。Recall@3 为前三名命中该证据组的题数占比；MRR@3 为第一个命中子块排名的倒数的平均值。每题最终均返回3个不同子块，指标经过独立复算。

时间题使用标注的 time_hint，不包含模型时间解析误差。50道无时间题在两条件中的结果相同，复用同一结果。

|---|---:|
| RRF Top20 | 143/150 |
| RRF Top10 | 143/150 |

`results.jsonl` 保存逐题候选ID、精排输入ID、最终正文、分数及原始证据映射；`config.json` 保存参数及源子块文件哈希；`summary.json` 保存汇总结果。临时 Milvus collection 已删除。该组参数仅用于本轮评测，未更改服务默认配置。
