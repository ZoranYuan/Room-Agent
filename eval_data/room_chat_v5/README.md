# Room Chat v5

固定种子生成的合成群聊检索集，用于本地验证查询拆分与子块召回。

- 10,000 条消息、50 个虚拟发送者；话题覆盖游戏、动漫和新闻。
- 200 道可回答题：100 道带时间表达，100 道不带时间表达。
- 每题含 1–3 个标注证据子块；统一按每题命中的 gold 子块数除以该题 gold 子块总数计算证据 Recall@3。
- 时间题覆盖明确日期、相对时间和“最近一次”；可在同一批时间题上对照不启用/启用时间排序。
- 父块按 50 条消息或 2,000 字符切分，子块上限 400 字符。
- `child_chunks.jsonl` 是按合成事件标签生成的基准子块，供检索评测使用；不是模型聚类输出。结果用于比较检索配置，不代表真实线上聊天分布。
- 当前不含无答案题，也不评估最终回答质量。

重新生成：

```bash
python eval_data/room_chat_v5/generate_dataset.py
```
