# Room Agent 多主题长跨度检索集 v2

v2 用来检查检索器在话题更分散、同一话题隔很久再续聊时的表现。它包含一个房间内 4,000 条按时间排序的合成聊天消息、88 个可回答问题和 20 个无答案问题，覆盖出游、露营、聚餐、工作排期、面试、设备选购、维修、运动、读书会、宠物照看、活动安排等 22 个主题。

每个主题拆成前后两段：第一段位于消息流前半部分，后续讨论位于后半部分，中间隔着大量其他话题和日常闲聊。35 个问题需要结合多条证据消息回答，`gold_seqs` 会记录这些证据的序号。所有消息和问题由固定随机种子生成，可重复生成。

## 运行

```bash
python eval_data/room_chat_v2/generate_dataset.py
MILVUS_URI=http://milvus:19530 uv run --no-sync python eval_data/room_chat_v2/run_retrieval_eval.py
```

评测使用生产消息聚类和切块逻辑，在独立临时 Milvus collection 中比较纯向量、混合 RRF、混合加 MiniLM 重排、混合加 Qwen3 重排。召回候选均为 Top-5，最终重排结果为 Top-3；结束后清理临时 collection。汇总指标只针对 88 个可回答问题，无答案问题不计入 Recall/MRR。

这是一套人工编写锚点对话、程序生成背景闲聊的合成评测集，适合做模型间的同集对比，不代表真实用户数据分布。正式结论还应使用未参与调参的问题集或真实脱敏样本复测。
